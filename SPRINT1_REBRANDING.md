# Sprint 1 - Rebranding SPES Configuratore Contabile 4.0

Modifiche incluse:

- nome e versione centralizzati in `app/spes_tools/version.py`;
- nuova dashboard con logo, card e barra di stato;
- splash screen iniziale con logo SPES;
- icona dell'applicazione e dell'eseguibile mantenuta;
- titoli e testi uniformati a **SPES Configuratore Contabile**;
- rimozione di cache Python dal pacchetto.

## Aggiornamento con GitHub Desktop

1. Aprire `Repository > Show in Explorer`.
2. Copiare il contenuto di questo pacchetto nella cartella del repository.
3. Confermare la sostituzione dei file.
4. In GitHub Desktop usare il riepilogo:
   `Sprint 1 - rebranding SPES Configuratore Contabile 4.0`
5. Premere `Commit to main` e poi `Push origin`.
6. Attendere la nuova build in GitHub Actions.
