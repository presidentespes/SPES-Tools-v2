# Aggiornamento 5.3.4 - Regolamento FGI integrato

- Il pulsante **Regolamento FGI** non apre più il sito web.
- Il PDF ufficiale T.U.N.S. 2027 è incluso nell'applicazione in `assets/docs/TUNS_2027.pdf`.
- Il documento viene aperto con il lettore PDF predefinito di Windows.
- Se il file o il lettore PDF non sono disponibili, l'app mostra un messaggio chiaro.
- Versione, installer e workflow aggiornati alla 5.3.4.
