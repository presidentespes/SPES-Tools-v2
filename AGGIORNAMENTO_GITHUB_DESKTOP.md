# Aggiornamento con GitHub Desktop

1. In GitHub Desktop aprire il repository `SPES-Tools-v2`.
2. Selezionare **Repository > Show in Explorer**.
3. Nella cartella clonata non eliminare la cartella nascosta `.git`.
4. Copiare qui tutto il contenuto di questo pacchetto e confermare la sostituzione.
5. Tornare in GitHub Desktop.
6. Nel campo **Summary** scrivere: `SPES Configuratore Contabile 4.0`.
7. Premere **Commit to main** e poi **Push origin**.
8. Su GitHub aprire **Actions** e controllare la nuova build.
9. Scaricare l'artifact `SPES_Configuratore_Contabile_4_0`.

Il repository non contiene EXE, ZIP, cache o ambienti virtuali. Questi elementi sono esclusi da `.gitignore`.
